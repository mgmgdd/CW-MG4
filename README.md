# CW-MG4
A lightweight enhancement utility for Android (Xposed/LSPosed module).
适配某车机互联应用，提供若干实用增强功能。
## 功能
- 桌面卡片增强
- 模式切换入口恢复
- 界面缩放调节
- 截图按钮
- 投屏帧率调节
- 更多实用工具
## 安装
1. 安装 APK，在 LSPosed 管理器中启用
2. 作用域勾选目标应用
3. 重启生效
## 构建
- CI：推送 / 打 tag 自动构建并发布 Release
